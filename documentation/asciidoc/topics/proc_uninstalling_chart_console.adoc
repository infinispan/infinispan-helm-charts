= Uninstalling the {brandname} chart through the {openshiftshort} console

[role="_abstract"]
Use the {osweb} to uninstall a {brandname} Helm release and remove the pods and other deployment artifacts it created.

ifdef::community[]
[NOTE]
====
This procedure applies to {openshiftshort} only.
On other {k8s} clusters, uninstall the release using the command-line method.
====
endif::community[]

.Prerequisites

* Have access to {openshiftshort}.
* Have an installed {brandname} Helm release.

.Procedure

. Log in to the {osweb}.
. Navigate to **Ecosystem** -> **Helm** to list the Helm releases in your project.
. Locate the {brandname} Helm release and select the options menu (three vertical dots).
. Select **Delete Helm Release**.
+
[TIP]
====
Alternatively, navigate to **Workloads** -> **Topology**, right-click the {brandname} Helm release, and select **Delete Helm Release**.
====
+
. In the confirmation prompt, enter the name of the release and then select **Delete**.
